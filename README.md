# HRM-full-stack-react-fastAPI-mongo-
front end url: https://hrm-fs-2.netlify.app/
backend hosted url: https://hrm-full-stack-react-fastapi-mongo.onrender.com/

when hitting the backend it may take 40 seconds - 1 min to give response in first time, then it will start working faster, (using free tier)
tech stack used:
react and tailwind CSS for front end
fast api for backend
mongodb for database


to run the app locally:
1) clone the repo:
2) create your python enviroment for fastapi, and install the packages mentioned in requirements.txt inside backend.
3) run the backend with command: `uvicorn main:app --reload`
4) in front end, run `npm i` to install the packages.
5) and `npm start` to start the server.

I will close the backend and my database by within few days, you can add your own mongo url in env file.
